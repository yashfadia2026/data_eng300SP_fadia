## Methodology

### Task 1 – Dataset Storage on S3
The MovieLens 1M dataset was checked for existence in the S3 bucket before downloading. If the dataset already exists in S3, the script skips downloading the dataset again. The raw MovieLens files are stored under the `ml-1m/` prefix in the S3 bucket.

### Task 2 – BERT Embeddings for Movies Released Before 1980
Movies released in or before 1980 were filtered by extracting the release year from the movie title. Each movie was represented as a text string combining its title and genre information. BERT embeddings were generated using HuggingFace `BertTokenizer` and `BertModel`. The embedding for each movie was taken from the `[CLS]` token of the final hidden state. These embeddings were saved to S3 as reusable intermediate outputs.

### Task 3 – Recommendations for Pre-1980 Movies
Two recommendation cases were created using the pre-1980 movie embeddings.

For the cold user, with no prior interaction history, the average embedding across all pre-1980 movies was used as the user representation. The five movies with the highest cosine similarity to this average embedding were recommended.

For the top user, a random user from the top 5% of users by rating count was selected. A user embedding was created by averaging the BERT embeddings of movies that this user rated highly. The final recommendations were generated using cosine similarity between this user embedding and candidate movie embeddings.

### Task 4 – Full Dataset Embeddings and Recommendations
The same embedding and recommendation process from Tasks 2 and 3 was repeated using the full MovieLens movie dataset. Full movie embeddings and recommendation outputs were saved to S3.

### Task 5 – Personal User Profile and Recommendations
A personal user profile was created by manually selecting and rating 10 movies on the MovieLens 1–5 rating scale. A user embedding was generated by averaging the embeddings of movies rated 4 or higher. Five recommendations were then generated using cosine similarity between the personal user embedding and the full movie embedding set. Both the personal profile and recommendations were saved to S3.

## Function Pipeline

The analysis is structured using reusable functions so the full workflow can be run step by step.

1. `load_movies()`  
   Loads the MovieLens movies dataset from S3.

2. `filter_movie_year()`  
   Extracts release year from movie titles and filters movies released in or before 1980.

3. `create_bert_text()`  
   Creates text inputs for BERT using movie titles and genres.

4. `create_raw_bert_embeddings()`  
   Uses HuggingFace BERT to generate movie embeddings from the `[CLS]` token.

5. `cold_user_recommendation()`  
   Generates recommendations for a cold user using the average movie embedding.

6. `select_top_user()`  
   Selects a random user from the top 5% of users by number of ratings.

7. `top_user_recommendation()`  
   Generates recommendations for a top user by averaging embeddings of highly rated movies.

8. `add_year_column()`  
   Adds a release year column to the full movie dataset.

9. `recommend_for_me()`  
   Generates recommendations for the manually created personal user profile.
